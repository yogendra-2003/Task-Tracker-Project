# Task-Tracker-Project
 Task Tracker application that helps users monitor the progress of their projects. Within each project, users can create, read, update, and delete tasks. Every task should include a title, description, progress status, and dates for creation and completion. Each user’s account will store their email, password, name, and country.
 
# To run the Frontend
cd frontend
npm install
npm start

# To run the backend
cd backend
npm install
node server.js
